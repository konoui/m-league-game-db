# 分析観点ガイド

## 基本統計指標

### 成績

- **和了率**: 和了した局数 / 総局数
- **放銃率**: 放銃した局数 / 総局数
- **流局率**: 流局した局数 / 総局数
- **流局聴牌率**: 流局時に聴牌した局数 / 流局した局数
- **1着〜4着回数**: 各着順を取った回数
- **トップ率**: 1着を取った割合
- **連対率**: 1着か2着を取った割合
- **ラス回避率**: 4着以外を取った割合
- **ベストスコア**: 試合終了時の最大持ち点
- **平均打点**: 和了時の平均点数
- **放銃平均打点**: ロンされた時の平均点数

### 戦術

- **副露率**: 副露した局数（小明槓・暗槓を除く） / 総局数
- **立直率**: リーチした局数 / 総局数
- **ダマ率**: 門前ダマで和了した局数 / 和了した局数
- **ツモ率**: ツモ和了した局数 / 和了した局数

### 効率

- **銃点損失**: 放銃率 × 放銃平均打点
- **打点効率**: 和了率 × 平均打点

## 分析軸

- **時間軸**: シーズン別、ステージ別（regular / semifinal / final）、暦年別、シーズンをまたぐ連続記録、巡目別（0順目（配牌時）/ 7順目 / 14順目 / 流局時）
- **対象軸**: プレイヤー別、チーム別、試合別、席別
- **統計軸**: 平均値、中央値、最大値、分布
- **状況・文脈軸**:
  - 点差状況（トップ目、ラス目、僅差の2着）
  - 親番 / 子番
  - 対戦相手（特定のチーム・選手との相性）
  - 試合の進行度（東場、南場、オーラス）

## テーマの例

- **順位・スコア**: 1試合の最高スコア、ラス回避率、各着順の連続回数
- **シャンテン数**: 0順目（配牌時）の平均シャンテン数、7順目の中央値のチーム・シーズン比較、仕掛けだしのシャンテン数
- **特殊状況**: 天和・地和が可能だった局、東1局と南1局の親の和了
- **相関・効率**: 配牌の良さと最終順位の関係、リーチ成功率と成績の関係
- **チーム戦略**: チーム内の役割分担、対戦相手との相性、月別の変動
- **時系列**: シーズン後半の成績の伸び、長期的な戦術の変化

## 発展的な分析

- **複合指標を作る**: 基本指標を組み合わせて独自の指標を定義する
  - リーチ成功率 = リーチ後の和了回数 / リーチ回数
  - 守備力指標 = (1 - 放銃率) × ラス回避率
- **ベンチマークと比べる**: リーグ全体の平均と比べて、選手・チームの特徴を浮き彫りにする
  - 例: リーグ平均より和了率が特に高い選手は誰か
  - 例: シーズンが進むとリーグ全体の副露率はどう変わるか
- **状況による変化を見る**: 特定の状況で基本スタッツがどう変わるか
  - 例: ファイナル進出者のリーチ率はレギュラーシーズンと比べてどう変わるか
  - 例: トップ目のときの副露率は通常時と比べてどう変わるか
- **問いを立てる**: 「絶好調の選手は誰か」「逆境に強い選手は誰か」のように具体的な問いを設定し、その答えを探るクエリにする
