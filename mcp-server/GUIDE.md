# Claude で M リーグのデータに質問できるようにする

Claude Desktop に拡張機能を 1 つ入れるだけで、「連続トップの最長記録は？」「役満を一番あがった選手は？」のような質問に、全試合のデータから答えてもらえるようになります。

所要時間は 3 分ほどです。プログラミングの知識はいりません。

## 用意するもの

- **Claude Desktop**（Mac または Windows）。まだなら [claude.com/download](https://claude.com/download) から入れてください。
- **`m-league-db.mcpb`**（配布ページからダウンロードします）… データを検索する拡張機能

## 手順

### 1. 拡張機能を入れる

1. Claude Desktop を開き、左下の自分の名前から **「設定」** を開きます。
2. **「Extensions」**（拡張機能）を開きます。
3. ダウンロードした `m-league-db.mcpb` を、この画面にドラッグします。
4. 確認の画面が出たら **「Install」**（インストール）を押します。

一覧に「M リーグ データベース」が出て、スイッチがオンになっていれば完了です。

### 2. 質問してみる

新しいチャットで、普通の言葉で聞いてください。

- 連続 4 着が最も多い選手とその期間は？
- 今シーズンのトップ率ランキングを教えて
- 小四喜をあがったのは誰？
- 佐々木寿人と多井隆晴の直接対決の成績は？

最初の質問のときに、次の 2 つが起きます。

- **ツールの使用許可を聞かれます。** 「常に許可」を選ぶと、次からは聞かれません。
- **データの取得で 10〜20 秒ほど待ちます。** 約 22MB のデータをダウンロードするためで、2 回目からはすぐに答えます。

データは 1 日 1 回、新しい試合があれば自動で更新されます。

## うまくいかないとき

| 症状 | 対処 |
| --- | --- |
| 「m-league-db が見つからない」と言われる | 手順 1 の拡張機能のスイッチがオンか確かめ、Claude Desktop を完全に終了（Mac は Cmd+Q）してから開き直す |
| 数え方が思っていたのと違う | 「シーズンで区切って」「20 試合以上の選手だけで」のように条件を足して聞き直す |
| 最初の質問でエラーになる | インターネットにつながっているか確かめる。初回はデータのダウンロードが必要 |
| 最新の試合が反映されていない | 「データを最新にして」と頼む |

## 知っておくとよいこと

- データは M リーグ公式の試合記録をもとにした [m-league-game-db](https://github.com/konoui/m-league-game-db) を使っています。
- 検索は読み取り専用です。あなたのパソコンのファイルを読んだり書き換えたりはしません。
- 答えには、Claude がどう数えたか（期間・区切り方・試合数の条件など）が書かれます。数え方が違うと結果も変わるので、気になったら「シーズンで区切って数えて」のように頼み直してください。
